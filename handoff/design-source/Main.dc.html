Foundations

One system for every page of eestec.mk

Red and white, Roboto, and a small set of shared components. Each piece below maps to a single React component or CSS token, so the Next.js build stays consistent from Home to the Admin Panel.

Colors

Red and white are the only brand colors. Neutrals are used only for text, borders and surfaces.
